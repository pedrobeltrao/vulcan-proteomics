## 1. Semi-specific index (L1)

`vulcan.lip.digest` enumerates the semi-specific digest the way Sage does: prefixes and suffixes of every specific peptide with ≤2 missed cleavages, length 7–50. Its specific digest is **identical to vulcan_core's** (682,404 = 682,404 sequences, 0 missed-cleavage mismatches). The digest is fed to the unchanged `vulcan.index.build.build`.

- **Size.** 11.5M forward peptides: 0.68M specific, 5.42M N-semi, 5.41M C-semi. That gives 33.3M peptidoforms (T + paired decoys).
- **Footprint and build time.** 7.1 GB on the GPU (835M postings, one slice). CPU build 279 s; GPU index build 6.3 s.
- **Decoys.** Every forward peptide gets its paired C-term-fixed pseudo-reverse. The specificity class is a property of the pair, so #decoys = #targets in every class.
  - This meets the purpose of DESIGN L1 ("decoys from decoy proteins so class counts match") exactly.
  - Literal semi digestion of reversed proteins would break 1:1 pairing (paired TDC, G0, family-max).
  - It would also start C-tryptic decoys with K/R instead of ending with it, so they would not be exchangeable. Recorded as an implementation reading of L1.
  - 315 forward peptides (0.003%) have no decoy after 50 collision redraws and are dropped.

## 2. LiP-MS on D7 (12 runs; LiP and TrP are separate experiments)

**IDs at 1%.** Peptidoform units, paired double competition, frozen `static_gbm_pred`, Group-walk over the specificity stratum.

| | Group-walk total | specific | N-semi | C-semi | pooled TDC | separate TDC per class (spec / N / C) |
|---|---|---|---|---|---|---|
| LiP (6 runs) | **26,976** | 15,906 | 6,611 | 4,459 | 26,858 | 16,132 / 6,184 / 4,444 |
| TrP (6 runs) | **21,743** | 19,798 | 1,242 | 703 | 21,212 | 19,985 / 910 / 686 |

- **Sanity check.** Semi-class IDs make up 41% of LiP vs 9% of TrP. That is the PK footprint, found label-free.
- **Half-tryptic calls on all identified LiP peptidoforms:**
  - 10,928 half-tryptic;
  - 15,906 tryptic;
  - 142 biological termini (excluded from cuts). Of these, 92 are Met removal, 34 are annotated signal/transit/propeptide/chain starts and 1 is a chain end.
  - Among quantified LiP peptidoforms: 8,983 half-tryptic, giving **8,473 unique cut sites in 1,368 proteins** (5,113 N-side, 3,870 C-side).
- **Flags (never filters):**
  - 288 half-tryptic peptidoforms (3.2%) co-elute within 0.1 min with a prefix/suffix parent in the same run: possible in-source fragments.
  - 872 half-tryptic peptidoforms are also identified in TrP runs (trypsin-only), i.e. not PK products.
  - TrP itself contains 1,779 half-tryptic peptidoforms (8% of IDs): endogenous proteolysis, in-source fragmentation or non-specific trypsin. This is why the TrP-adjusted MSstatsLiP model matters.
- **MBR.** Run within each digest group only, never LiP↔TrP (M6 default: 0.1% donors, per-run transfer q ≤ 1%). It accepts 3,553 LiP and 10,331 TrP transfers, all provenance-flagged.
- **Output** (`/tmp/vulcan_m5lc/lip`, not committed; regenerated by `scripts/m5lc/lip_quant.py`):
  - peptide × run matrices with protein, start/end, cut site, side and call (`matrix_{LiP,TrP}.tsv.gz`, plus provenance matrices);
  - `lip_long.parquet`;
  - MSstatsLiP input `msstatslip_{LiP,TrP}.csv`. The feature is the precursor (peptide × charge × Met-ox count); proteotypic peptides only.

**MSstatsLiP 1.8.1 ran** (bioconda env `conda_envs/rlip`; summarisation 121 s, comparison 124 s). For F1 vs M1, 10,852 LiP peptides were tested and 1,972 TrP proteins. At adj.p < 0.05: 461 significant in the TrP-adjusted model, 816 unadjusted.

**Known-target truth: alpha-synuclein (P37840) fibril vs monomer.** 118 SNCA LiP peptides were tested.
- **20 are significant (TrP-adjusted adj.p < 0.05), and all 20 overlap the fibril core / NAC region (residues 37–99); none are outside it.**
  - 17 lie in residues 34–97.
  - 3 start at D98 with C-terminal cuts at 110/115/119, at the core's C-terminal edge.
- **Pattern.** Half-tryptic peptides with PK cuts inside the core go *down* in fibrils:
  - EGVVHGVA(T) cut 53/54: −5.7/−6.4 log2;
  - EQVTNVGGA… cuts 69–73: −3.6 to −5.0;
  - TVEGAGSIA(A) cuts 89/90: −4.3/−3.1.

  Longer tryptic/semi peptides spanning the core go *up*: NVGGAVVTGVTAVAQK +6.4, EGVVHGVATVAEK +3.2, TVEGAGSIAAATGFVKK +2.7. That is the expected protection of the amyloid core from PK.
- **TrP control.** SNCA abundance in TrP: log2FC +0.75, adj.p 0.22 (not significant), so the change is structural, not abundance.
- **Caveat.** This is a dev truth with no peptide-level table; it is the region-level expectation from the protocol paper and fibril structures.

## 3. CF-MS: E10 on D10cf (29 SEC fractions; fractions 10–14 are void, 0–322 IDs)

**Policy implemented in `vulcan.cf.transfer`:**
- **Run-specific per-fraction q.** `ids.py --per-run`; series-pooled q is kept as `pf_q_series`.
- **Provenance flags.** Values are `ms2` / `transfer_local` / `transfer_global`, each with a transfer q.
- **Fraction-local donors.** Donors come only from fractions f ± 1, with per-acceptor transfer q (M6 PIP-ECHO decoys).
- **Profile-agnostic score.** The M6 score with the intensity-consistency term removed (`_best_in_window` with the intensity weight → 0). Nothing reads donor or neighbour intensities.
- **No normalization anywhere.**

**Scoring constraint.** The MS2 scans are ion-trap CID, so the search used ±600 ppm fragments and **plain hyperscore** paired TDC: there is no IT-CID static model (tree 3c). IDs are 0.3k–10.1k peptidoforms per fraction (16–38: 4.6k–10.1k).

**Entrapment.** Paired shuffled entrapment (seed 2001, r = 1) is in the index. MS2 values combine to an entrapment FDP estimate of 2N_E/(N_T+N_E) = 0.28% at run-level 1% (238 entrapment vs 171,388 target values).

**E10 table** (identical MS2 IDs in every mode; transfer q ≤ 1% except naive):

| mode | transferred values (target) | precursor fractions, median / mean ratio vs none | protein FWHM ratio | protein n-fractions median | transfers ≥3 fractions from any MS2 of the same protein | CORUM PR-AUC, common 1,513 proteins (prevalence 0.018) | CORUM PR-AUC, own eligible set |
|---|---|---|---|---|---|---|---|
| none | 0 | 2 / 1.00 | 1.00 | 4 | – | 0.0757 | 0.0757 (1,513) |
| **fraction-local** | 33,247 | 3 / 1.20 | 1.08 | 5 | **0.0%** | 0.0820 | **0.0781** (1,575) |
| global MBR (transfer q) | 6,196 | 2 / 1.04 | 1.01 | 5 | 3.9% (28% ≥3 from the same precursor) | 0.0757 | 0.0738 (1,527) |
| global naive (no transfer FDR) | 106,703 | 4 / 1.77 | 1.17 | 9 | **9.2%** (41%) | 0.0883 | 0.0728 (1,653) |

How to read it:
- **Unconstrained MBR inflates elution profiles.** Without a transfer FDR: +77% fractions per precursor, protein peaks twice as wide by n-fractions (FWHM 1.17×). 9% of its values sit ≥3 fractions from any MS2 evidence for the protein, i.e. secondary "peaks" MS2 never saw. Fraction-local transfer places none there by construction.
- **The transfer FDR largely self-limits global MBR.** With per-acceptor q, the unconstrained donor pool is mostly truly absent in a given fraction, so the null fraction is high and only 6.2k transfers pass, vs 33k for fraction-local. Fraction-local gives more values at controlled q precisely because adjacent-fraction donors are plausible.
- **The DESIGN hypothesis is only partly supported.**
  - Supported for width and off-peak artifacts.
  - **Not supported for CORUM PR-AUC:** on the common protein set, naive global MBR gives the *highest* PR-AUC (0.088 vs 0.076 none, 0.082 local). Filling in missing values inside true elution peaks helps correlation more than off-peak artifacts hurt it at this depth. On each mode's own eligible proteins, naive is lowest (0.073) and fraction-local is highest (0.078).
  - PR-AUC differences are small; no CI was computed.
- **Entrapment null (false co-elution) is underpowered.** Only 13–17 entrapment precursors have ≥3-fraction profiles; nearly all reach max r ≥ 0.8 to some real protein profile in every mode. r ≥ 0.8 entrapment–protein pairs: 1,395 none, 1,845 local, 1,406 global, 2,424 naive.
  - The combined entrapment FDP among transferred values is ≤0.11% in every mode. This reflects mainly the 0.1% donor level: entrapment donors are rare, and the entrapment null only sees propagated ID error, not peak mis-assignment.
  - The PIP-ECHO RT-decoy estimate of the naive set's false fraction is 1.7%.
  - **A spiked foreign-proteome CF set is still needed** for a real false co-elution measurement.

## 5. Issues / open
1. **FASTA concatenation bug (caught, fixed, re-run).** `contaminants_frankenfield2022.fasta` has no trailing newline. `cat a b c` glued the P37840 header onto the last contaminant sequence, so SNCA was silently absent from the first LiP index (and 27 "invalid" letters appeared). All reported LiP numbers come from the corrected FASTA (newline-safe join). → LESSONS.
2. **CF is IT-CID.** D10cf MS2 is ion-trap CID, not Orbitrap HCD. It was searched at ±600 ppm and scored by hyperscore only. Depth is therefore modest, and the frozen OT-HCD model cannot be used. An OT-HCD DDA CF set (or the IT-CID model, 3c) would make E10 more sensitive.
3. **No entrapment in the LiP index.** The half-tryptic stratum's FDR is not yet entrapment-verified (Group-walk gives 160 decoys above threshold in N-semi vs 6,611 accepted, plus a stratum-imbalanced allocation). Next: a paired-entrapment semi index, or arm M (yeast + SNCA vs human entrapment) on the semi search. Separate per-class TDC counts are reported alongside.
4. **The static scorer was trained on tryptic data.** It is applied unchanged to semi-specific candidates (label-blind, so valid, but possibly sub-optimal for half-tryptic sensitivity).
5. **Sage comparison** uses different estimators (see §2). The predictor cache was cold for semi peptides (≈43 s for the first run).
6. **E10 limits.** One replicate series and 29 of 61 fractions (fractions 10–14 are void). PR-AUC has no CI. The entrapment null is underpowered. CORUM comes via OmniPath because CORUM's own server was unreachable from the node.
7. **SNCA truth is region-level.** There is no peptide-level table; the expected-change region (fibril core 37–99) is literature-defined and not tuned on these data.
